# Invitation de mariage

Site statique pour l'invitation de Loïc et Ruth. Il fonctionne sans base de données ni serveur applicatif.

## Déployer gratuitement sur Vercel

1. Créer un dépôt GitHub et y envoyer ces fichiers.
2. Aller sur [vercel.com](https://vercel.com), créer un compte puis choisir **Add New Project**.
3. Importer le dépôt GitHub.
4. Laisser les réglages par défaut, puis cliquer sur **Deploy**.

Vercel détecte automatiquement le site HTML. Chaque modification envoyée sur GitHub sera ensuite publiée automatiquement.
